↓ Installation

ai9s is a single Go binary. It runs on macOS, Linux, and Windows. GitHub Actions tests it on Ubuntu, macOS, and Windows. Install the latest 1.0 release. The supported line is 1.0.x.

Homebrew

Homebrew works on macOS and Linux.

brew tap AymanZahran/ai9s https://github.com/AymanZahran/ai9s
brew trust aymanzahran/ai9s
brew install ai9s

The formula is Formula/ai9s.rb in this repository. brew tap AymanZahran/ai9s with no URL looks for a repository named homebrew-ai9s, so pass the URL above. brew install --HEAD ai9s builds the latest main.

Linux packages

Each command installs the latest published release. Use amd64 on x86_64 and arm64 on aarch64.

Debian and Ubuntu

curl -fL -o /tmp/ai9s.deb https://github.com/AymanZahran/ai9s/releases/latest/download/ai9s_linux_amd64.deb
sudo dpkg -i /tmp/ai9s.deb

Fedora, RHEL, and CentOS

sudo dnf install -y https://github.com/AymanZahran/ai9s/releases/latest/download/ai9s_linux_amd64.rpm

Alpine

curl -fL -o /tmp/ai9s.apk https://github.com/AymanZahran/ai9s/releases/latest/download/ai9s_linux_amd64.apk
sudo apk add --allow-untrusted /tmp/ai9s.apk

Arch Linux

git clone --depth 1 https://github.com/AymanZahran/ai9s.git
cd ai9s/packaging/arch
makepkg -si

Windows

Scoop

scoop install https://raw.githubusercontent.com/AymanZahran/ai9s/main/packaging/scoop/ai9s.json

Zip

ai9s_Windows_arm64.zip is the arm64 build. Put the extracted ai9s.exe on PATH.

$dest = "$env:LOCALAPPDATA\ai9s"
New-Item -ItemType Directory -Force -Path $dest | Out-Null
Invoke-WebRequest https://github.com/AymanZahran/ai9s/releases/latest/download/ai9s_Windows_amd64.zip -OutFile "$dest\ai9s.zip"
Expand-Archive "$dest\ai9s.zip" -DestinationPath $dest -Force

From source

git clone https://github.com/AymanZahran/ai9s.git
cd ai9s
make install

make install copies the binary to ~/.local/bin. Put that directory on your PATH, or choose another prefix:

make install PREFIX=/usr/local

With the Go tool

Requires Go 1.25 or newer.

go install github.com/AymanZahran/ai9s@latest

The binary lands in $(go env GOPATH)/bin.

Check

ai9s version
ai9s

With no arguments, ai9s indexes and opens the list. A non-terminal stdin prints a short message and exits, so scripts should call ai9s search or ai9s stats.

Terminal

Use a terminal with 256 colors. On Unix-like systems:

export TERM=xterm-256color

The list fills the window. d describes the selected row in that same window, and Esc returns to the list. The mouse wheel scrolls the view on screen. Resume needs the agent CLI on PATH. ai9s does not embed those CLIs.

Where the index lives

The cache database is the first of these that applies:

  1. $AI9S_CACHE_DIR/index.db
  2. $XDG_CACHE_HOME/ai9s/index.db
  3. ~/.cache/ai9s/index.db

It stores titles, metadata, and short excerpts, not a second full copy of every log. Delete that directory any time. The next run rebuilds it from the agent files.
