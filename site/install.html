↓ Installation

air9s is a single Go binary. It runs on macOS, Linux, and Windows. GitHub Actions tests it on Ubuntu.

Homebrew

brew tap AymanZahran/air9s
brew trust aymanzahran/air9s
brew install air9s

The formula is in AymanZahran/homebrew-air9s. brew install --HEAD air9s builds the latest main once that repository can be cloned over HTTPS. While those repositories are private, tap over SSH, trust the tap, and export a GitHub token so Homebrew can download the release archive. Install that tagged formula. --HEAD cannot clone the private source repository over HTTPS.

brew tap AymanZahran/air9s git@github.com:AymanZahran/homebrew-air9s.git
brew trust aymanzahran/air9s
export HOMEBREW_GITHUB_API_TOKEN="$(gh auth token)"
brew install air9s

From source

git clone https://github.com/AymanZahran/air9s.git
cd air9s
make install

make install copies the binary to ~/.local/bin. Put that directory on your PATH, or choose another prefix:

make install PREFIX=/usr/local

With the Go tool

Requires Go 1.25 or newer.

go install github.com/AymanZahran/air9s/cmd/air9s@latest

The binary lands in $(go env GOPATH)/bin.

Check

air9s version
air9s

With no arguments, air9s indexes and opens the list. A non-terminal stdin prints a short message and exits, so scripts should call air9s search or air9s stats.

Terminal

Use a terminal with 256 colors. On Unix-like systems:

export TERM=xterm-256color

The list fills the window. d describes the selected row in that same window, and Esc returns to the list. The mouse wheel scrolls the view on screen. Resume needs the agent CLI on PATH. air9s does not embed those CLIs.

Where the index lives

The cache database is the first of these that applies:

  1. $AIR9S_CACHE_DIR/index.db
  2. $XDG_CACHE_HOME/air9s/index.db
  3. ~/.cache/air9s/index.db

It stores titles, metadata, and short excerpts, not a second full copy of every log. Delete that directory any time. The next run rebuilds it from the agent files.
