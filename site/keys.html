⌨ Keys

The same manual is inside the program. Press ?. j and k scroll it, g and G jump, and Esc, q, or ? returns to the list.

Hotkeys are drawn on the top two lines. The active view is bold. Angle brackets mark the key, in the same style as k9s.

KeyAction
1–5Sessions, providers, directories, branches, models.
EnterResume the selected session. On a group view, apply that group as a filter and return to sessions.
j / kMove down or up in the list. In the preview or the manual, scroll a line.
TabFocus the preview. Tab or Esc returns to the list.
/Edit the filter text.
:Command mode. Type a view name or a filter token. Enter applies it. Enter on an empty command cycles the view. Another : cycles the view name in the field. Esc closes it.
d, Ctrl-DDelete, after confirmation. Sessions view only.
aCycle the agent: filter.
pAdd a dir: filter and focus the filter line so you can finish it.
oCycle sort: recent, oldest, messages, title.
yToggle yolo for the next resume.
rReindex.
sStats.
?Scrollable manual.
qQuit.

Preview

While the preview is focused, j and k or the arrows scroll a line. Page Up, Page Down, Ctrl-B, and Ctrl-F scroll a page. g and G jump to the top or the end. The mouse wheel scrolls when the pointer is over the preview.

Group views

Providers, directories, branches, and models group the current filtered list. Enter on a row sets the matching token and returns to sessions. A row labeled (none) has an empty value, so Enter leaves the filter alone. Resume and delete stay on the sessions view. From a group view, delete tells you to switch back first.

Command mode

The table lists view names and tokens: agent:, dir:, branch:, model:, date:, and sort:. Typing narrows that list. Enter on a token with a value rewrites that token in the filter and returns to sessions. Enter on a token with no value focuses the filter so you can type the rest, the same way p does.
