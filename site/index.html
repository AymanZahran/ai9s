⌘ Who left the agents running?

air9s is a terminal UI for the AI coding sessions already on your machine. It indexes them locally, then lets you search, preview, filter, resume, and — where it is safe — delete them.

The list works like a cluster browser: a hotkey menu, a crumbs bar, and one framed table. d describes the selected row. Ctrl-D deletes. Colors and plugins live in a config file, the same way k9s does. Each agent keeps the mark it actually prints. Nothing is uploaded.

brew tap AymanZahran/air9s
brew trust aymanzahran/air9s
brew install air9s

Source and go install are on the install page. Building from source requires Go 1.25 or newer.

▣ Features

  • Sessions at your fingertips
    • Claude, Codex, Copilot CLI, Grok, Antigravity, Gemini CLI, Cursor, OpenCode, Hermes, OpenClaw, Junie, Jules, Goose, Cline, Aider, and Kiro.
  • Keyboard first
    • Hotkeys stay on the top row. / edits the filter. : opens views and filter tokens. ? opens a scrollable manual.
  • Five views
    • 1 through 5 switch sessions, providers, directories, branches, and models. Branches shows the git branch and the worktree. Enter on a group applies that filter.
  • Preview you can actually read
    • d replaces the list with the excerpt. j and k scroll it. Esc returns to the list. Ctrl-D deletes.
  • Resume in the original directory
    • Enter runs that agent's own CLI. --yolo adds an approval flag only when the agent documents one.
  • Delete only when one file, one directory, or one CLI call is enough
    • Grok, Gemini, Jules, and Kiro stay read-only. The preview says why.
  • A local index
    • SQLite under your cache directory. Files are skipped when their modification time has not changed. One agent failing does not drop the others.
  • Metadata when the agent recorded it
    • Context size, window, tokens, cache, reasoning, cost, and premium requests. The CTX column is the latest prompt size, not a sum of every turn.
