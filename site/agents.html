Yolo

air9s resume --yolo adds a flag only when the agent documents one:

  • Claude and Antigravity: --dangerously-skip-permissions
  • Grok: --always-approve
  • Copilot: --allow-all-tools
  • Cursor: --force
  • Hermes: --yolo
  • Junie: --brave
  • Cline: --yolo on task open
  • Kiro: --trust-all-tools before the subcommand

Codex, Gemini, OpenCode, OpenClaw, Jules, Goose, and Aider resume without an extra approval flag.

Read limits

  • Subagent transcripts are skipped.
  • Kiro's shell history table is skipped. Resume uses kiro-cli, which is separate from the Kiro IDE.
  • Goose resume and delete need the goose command on PATH.
  • Jules listing talks to Google only when AIR9S_JULES_REMOTE=1. Otherwise air9s reads the local snapshot and does not run jules. Deleting a remote session uses the Jules API when JULES_API_KEY is set.
  • Aider does not walk the home directory unless AIDER_SCAN_HOME=1.
  • OpenClaw's working directory is the workspace recorded on the session. air9s does not read OpenClaw credentials.

What delete removes

Grok delete removes the one session directory whose name is that session id, when summary.json is a regular file inside it. It also drops that id from active_sessions.json and client-state/session-meta.json when those files exist. The project prompt_history.jsonl stays.

Gemini delete removes that one session-*.json file under tmp/<project>/chats/, after the file's sessionId matches. Project caches and projects.json stay.

Kiro delete removes that conversation from conversations_v2 and, when the same key is present, from conversations. The shell history table is left as it is. The database file stays.

Jules keeps a local list in sessions.json or sessions.txt. Delete rewrites that file without the chosen id. The jules command has no delete subcommand. A remote session is deleted with the Jules API when JULES_API_KEY is set. Without that key, the cloud session is left in place and delete says so. air9s does not read the Jules keyring.

Antigravity stores every conversation in one history.jsonl. Delete rewrites that file without the chosen id. Cline delete rewrites taskHistory.json first, then removes that task's directory. OpenCode, Hermes, OpenClaw, and Goose delete through each CLI. Other deletes remove a single transcript or Aider history file, or one Copilot session-state or Junie session-* directory, and only when the path is still inside that agent's session root.

Not indexed yet

These need a stable file layout and a real resume command before an adapter should claim them: Copilot in VS Code, Kimi, Qwen, Pi, Crush, Vibe, and Prime. Adding one is described in Contributing.

Icons

Each icon is two columns wide. The glyph is one that product prints. Cursor's logo is a picture, so its cell is blank. Jules, Goose, Cline, and Aider print a name and no glyph, so those cells are the first two letters of the name. An unknown agent is shown as ⚪.
