air9s

AI session CLI to resume your agents in style!

>_ Commands

air9s                         open the session list
air9s index                   scan agent session stores
air9s stats [--json]          counts by agent
air9s search [query] [--json] [--limit N]
air9s show <id> [--json]
air9s resume <id> [--yolo] [--print]
air9s delete <id> [--yes]
air9s info
air9s version
air9s help

index

air9s index scans every configured agent store and refreshes the local database. Files whose modification time has not changed are skipped. A scan error for one agent is printed as warning: and does not remove the other agents. --json prints session and message counts.

Opening the UI runs the same refresh first.

stats

air9s stats prints counts from the index. It does not scan again. Agents with zero sessions are omitted. --json prints the same counts as objects.

search

Each word is a substring of the title, summary, directory, branch, model, agent, or excerpt. Tokens such as agent: and dir: narrow the list the same way. A leading ~ expands. See Filters.

air9s search 'agent:claude dir:my-repo date:<7d auth'

--json prints sessions without excerpts. --limit caps the rows. The UI caps a search at ui.limit in the config, which defaults to 400.

info

air9s info prints the config file, the index database, the active skin, and how many plugins loaded. The first run creates config.yaml, skins/stock.yaml, and plugins.yaml when they are missing. See Config.

show

air9s show claude:<id> prints one session, including the excerpt and any recorded context or token counts. --json includes snippets.

resume

Resume runs that agent's CLI in the session directory when the directory still exists. --print writes the command and does not run it. --yolo appends a documented auto-approve flag, and only for agents that have one. The flags are listed on the agents page.

air9s resume claude:<id>
air9s resume codex:<id> --print

delete

Delete asks you to type the native id. --yes skips that prompt. If stdin is not a terminal, delete refuses unless --yes is set. Agents that cannot be deleted safely print the reason and leave the files alone.

air9s delete claude:<id>
air9s delete claude:<id> --yes

Identifiers

An id is the agent name, a colon, and that agent's own session id: claude:abc, hermes:hs-1, kiro:conv-1. Hermes profiles that are not default use hermes:p:<profile>:<id>.
