# Release v0.0.1

- ai9s is a terminal UI for the AI coding sessions already on your machine. It indexes them locally, then lets you search, preview, filter, resume, and delete them from one list.
- The version, commit, and date are set with `-ldflags` when the binary is built. Pushing a `vX.Y.Z` tag is the release. GoReleaser publishes the GitHub Release.
